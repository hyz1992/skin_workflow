# UI 换皮资源

取得选定设计、完整组件与状态清单、已有资源及当前授权。没有设计文件但已有清楚的资源需求时也可开始，不强制补一张母版。三个 ui-skin 目录应一起复制，共用工具就在本 skill 的 `scripts/assets.py`。

## 选择最少的有效生产工作

核对可复用文件的实际字节、尺寸、透明度及造型。合格对象原样复用，缺件才制作；局部修改不重生整批。若发现缺少组件或状态，先补清单，不能交付默认画面的几张图就称覆盖完整。

先说明背景保留什么、去除什么，再处理独立前景。动态文字交给程序；固定艺术字按设计保留。背景中遮挡内容的重建属于补绘，不能当作精确裁切。像素连通区域、提示词网格与透明边缘都不能自动确定语义区域。

图片生成/编辑使用当前环境实际可用的能力，并遵循其工具规则和用户偏好。已有 SVG/字体/程序几何可直接透明导出，不强制先生成位图再去底。默认优先有效 RGBA 复用，再选择可用透明输出或合适的去底方式；不把某个网站、账号或本地算法作为通用硬依赖。

采用外部去底服务时确认授权覆盖当前素材与目的地；有授权直接沿用。实际结果仍检查构图、固定文字、孔洞、细边和底色污染。确认棋盘格烘焙进图片后拒绝该输出并换路线；同路线同类失败两轮后调整方法。失败不使有效源图失效，不能为绕过限制偷偷换目的地。

## 共用工具

以下 `$TOOL` 代表**本 SKILL.md 所在目录**下 `scripts/assets.py` 的绝对路径，不是目标项目根目录。使用 Python 3.10+ 与 Pillow；先找环境现有运行时，缺少依赖时可在任务虚拟环境安装 `scripts/requirements.txt`，不要更改系统 Python。其他阶段无需为读说明安装依赖。

```sh
python "$TOOL" example                         # 输出最小清单示例，不写文件
python "$TOOL" inspect button.png             # 实际 PNG 解码、SHA、Alpha 与可见边界
python "$TOOL" slice atlas.png --rect 10 20 80 60 --output button.png
python "$TOOL" check assets.json
python "$TOOL" preview assets.json --output asset-preview.html
```

`slice` 只做用户要求的确定性原像素裁切，保留 Alpha 与留白，不去底、不重绘；区域须由实际看图确认。输出解码像素与源区域核对，并在终端返回来源与区域信息，保存到该资源的 `provenance`。所有命令拒绝覆盖已有输出。工具失败时修复实际问题，不修改历史检查结果来制造通过。

## 最小资源清单

在本次候选目录写 `assets.json`，完整形状可执行 `example` 查看。固定格式 `ui-skin-assets-v1`；`id` 是本批版本，`designSize` 是设计画幅，统一左上原点、X 向右/Y 向下。每个资源记录：

- `key`：稳定逻辑角色；`file`：包内相对路径；`sha256`：实际文件哈希。
- `pixelSize`：PNG 实际宽高；`displaySize`：设计单位下的显示宽高，默认等比。
- `transparency`：`required` 为需真实透明的前景，`opaque` 为不透明背景，`any` 为明确不限制；不要以 `any` 绕过前景检查。
- 可选 `position` 为画布中的锚点坐标，`anchor` 为归一化锚点（默认中心），`z` 为层级，`states` 为用途，`provenance` 记录来源/裁切/重采样，`notes` 说明限制。
- 有意拉伸的纯色或几何载体才设置 `resizeMode: stretch` 并在 notes 解释；完整插画保持默认 `uniform`。九宫格或程序绘制等额外规则放页面交接中，工具不假装验证这些渲染行为。

每个角色默认交付一个独立 PNG；合图可用于中间生产。用户要求图集时保留其要求并单独交接区域映射，说明当前工具只检查独立 PNG 清单，不能为了通过工具违背交付选择。字体、音频不冒充 PNG；在原型交接中记录实际路径和来源。

## 自审与交付

先挑具有细边/孔洞的代表件验证，再展开同族。`check` 只证明清单与文件的一致性及基础图像条件，无法识别残余棋盘、错字、语义或审美；多底色实际看图仍由 AI 完成。

`preview` 生成自包含网页，逐件展示棋盘/白/暗/灰/可调整页面底色、原始像素和设计尺寸、哈希及完整源图。实际查看目标显示大小与放大边缘，检查引用的是当前版本；打开请求成功不等于浏览器已看过。资源审核不能只给整页或一张合图。

交付实际 PNG、`assets.json`、预览网页与简短剩余缺件说明。透明对象未完成去底时只能标为过程稿，不当作切图成品提交审核。批准绑定用户实际看到的版本和范围，技术通过不代填批准。候选另存版本，Git 与归档操作遵循当前项目约定及授权。

继续网页组装时使用相邻 `ui-skin-prototype`，携带布局、字体/动态字段、状态/动作和资源选择范围；不要求原生截图，也不启动原生实现。
