# UI 换皮网页原型

从本次设计、选定资源与用户要求直接组装真实组件。三个 ui-skin 目录一起分发；共享检查工具位于相邻 `../ui-skin-assets/scripts/assets.py`。组装所需资料以本次设计、资源和目标页面约定为准。

## 获取布局与资源

核对实际资源版本、哈希、选择/批准范围、图片画布与可见区域，取得动态字段、关键状态及动作。可先运行共享工具 `check <assets.json>`；用户给的是其他格式时适配读取，不强制其重走设计或切图。缺少新图交给资源阶段；已有完整素材时直接组装。

从设计约定取得画幅、目标视口和安全区需求，不预设横屏或固定分辨率。记录设计单位、图片像素、CSS pixels 的区别，以及各组锚点、宽度封顶、裁剪/滚动/重排规则。全屏背景和前景各自适配，不拉伸整页来伪装响应式。目标背景覆盖不足时明确缺件，不用透明边或模糊复制填补冒充完成美术。

## 组装网页

使用相对资源路径、普通脚本和内联数据，交付 `prototype.html` 及所需文件。避免依赖本地 fetch JSON、ES module、CDN、后端或临时服务，保证可以离线打开。字体需要打包实际文件及适用的来源/许可说明；不要静默换字体后称为还原。

可按需复制本 skill 的 `assets/preview-shell.html` 作为比例切换和预览外壳；它是空壳，必须替换设计尺寸并填入真实组件、状态和布局规则，不是成品或通用 JSON 场景引擎。已存在合适网页时直接修改，不强制用模板。

实际 PNG 各自成为图片/背景节点；动态昵称、数量、价格和正文用程序文字。完整插画保持比例，头像内容与边框、图像可见范围与点击范围分别处理。不能用整页母版叠热点冒充组件组装。

按照真实页面语义模拟页签、开关、滚动、输入及弹层。只使用明确示例数据，不调用真实账号、支付、库存或设置服务。需要保留业务规则时从可用源码核对；无法核对的假设记在交接中，不把演示当作真实业务。

控件用稳定外层命中区，按压只缩放内部视觉层。覆盖按下、松手、移出、取消、失焦恢复和适用的键盘行为；原生 DOM 按钮优先用浏览器命中。只有 canvas/拖拽等自定义交互才自行转换指针坐标，使用容器实际矩形和缩放，不能重复换算。

## 实际验证

先看默认整页与母版对照，尤其是面板内部装饰、固定文字、透明留边、控件比例和对齐；再用长数据、空态、禁用、关键状态转换及窄/宽视口体验。局部组件必须放回整页看，不以单件漂亮替代整体成立。

用环境可用的浏览器工具打开最新文件，实际检查相关点击、滚动、取消与比例切换。file 协议受限时可用临时 HTTP 预览，但仍交付离线文件；未实际打开时准确记录浏览器验证未完成，不改用模拟器或伪造通过。原型不执行原生构建、取证或业务接线。

按变化和风险选择代表状态；不要默认生成所有状态×比例×按钮的截图矩阵。检查通过只覆盖实际体验的项目，技术检查、视觉自审与用户认可分别记录。

## 可携带交付

运行目录仅保留当前网页、真实依赖与 `handoff.json`。交接写清：设计画幅与坐标、所用资源清单、组件布局/热区、文字样式、动态字段、状态/动作映射、实际验证范围、缺口，以及用户已明确认可的版本。复杂布局以网页源代码为准，交接文件解释关键规则，不复制另一套会漂移的全量坐标表。

无需生成额外说明体系或审批状态机。可用共享工具冻结整个最终目录；先检查目录中仅有本次可交付文件，不夹带草稿、账号数据或无关内容：

```sh
python "$TOOL" snapshot deliverable --entry prototype.html --output deliverable-frozen
python "$TOOL" verify-snapshot deliverable-frozen
```

这里 `$TOOL` 是相邻资源 skill 工具的实际绝对路径。快照复制原字节并绑定所有文件哈希，跨机器可复验；它证明完整性，不证明脚本没有外部依赖或布局已获批准。若后续修改，另建版本重新验证，不覆盖冻结包。

交付可点击的离线入口，尽可能在浏览器展示，并说明已体验状态与剩余事项。遵守目标项目已有版本管理约定，不自行创建分支、合并、推送或启用业务。工作到网页原型和交接为止。
